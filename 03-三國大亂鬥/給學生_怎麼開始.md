# 🗡️ 三國大亂鬥：怎麼開始

## 一、安裝遊戲（第一次才要做）

1. **安裝 Godot**：到 <https://godotengine.org/download> 下載 **Godot 4.7**（標準版）。下載後解壓縮，雙擊裡面的 Godot 程式就能打開，不用安裝。
2. **下載課程**：到老師給的 GitHub 網頁，按綠色的 **Code** → **Download ZIP**，下載後**解壓縮**。
3. **匯入三個專案**：打開 Godot →「匯入（Import）」→ 選資料夾裡的 `project.godot` →「匯入並編輯」。三個資料夾都要匯入：

   | 資料夾 | 在 Godot 裡叫 | 什麼時候用 |
   |---|---|---|
   | `03-三國大亂鬥-成品` | 三國大亂鬥（成品） | 第一次上課開頭，先玩 |
   | `03-三國大亂鬥` | 三國大亂鬥 | **你上課要做的** |
   | `03-三國大亂鬥-抓蟲版` | 三國大亂鬥（抓蟲版） | 第二次上課抓蟲 |

4. 按 **F5** 開始玩！

## 二、用 Codex 幫忙（第二次上課才開放）

1. 打開 Codex，**開啟 `03-三國大亂鬥` 這個資料夾**（不是外面那一層 `kid-game-course`）。
   這樣 Codex 才會讀到資料夾裡的 `AGENTS.md`，知道要怎麼教你。
2. 把下面的「範本」複製到 Codex，把 ＿＿ 換成你自己的話再送出。
3. 記得軍規：**檢查器改得到的自己改，不要叫 AI。**

---

## 三、跟 Codex 說話的範本（複製貼上用）

### 🟢 範本 1：開始上課
```
我是三國大亂鬥課的學生，今天是第 ＿ 次上課。
請照 AGENTS.md 的規則幫我：不要直接幫我做完，先問我問題，讓我自己想。
```

### 🔵 範本 2：我看不懂（只問，不要改）
```
請用小學生聽得懂的話，解釋 ＿＿（檔案名稱）裡這一行在做什麼：
＿＿（把那一行貼過來）
只要解釋就好，不要改程式。
```

### 🟠 範本 3：我想做新東西（三句話）
```
① 我要改：＿＿
② 改完應該長這樣：＿＿
③ 我會這樣確認它改好了：＿＿
我猜你會改這些檔案：＿＿
請先告訴我你的計畫，我說「好」你再改。
```

### 🔴 範本 4：我發現 bug（抓蟲）
```
我做了：＿＿
我希望發生：＿＿
實際上發生：＿＿
我猜問題在：＿＿
請先給我一個提示，讓我自己找，不要直接修好。
```

### 🟣 範本 5：我卡住了
```
我卡住了：＿＿
請問我一個問題幫我想，不要直接告訴我答案。
```

### ⚪ 範本 6：AI 改完之後
```
你剛剛改了哪些檔案、哪幾行？
我要怎麼測試，才知道改對了？
```

---

**小提醒**：AI 改完一定要自己按 F5 測試，再指給老師看 AI 改了哪裡。說不出來，就先不要叫下一次！
