# 神殿大逃脫（第 2 款）— 給 AI 的說明

請先遵守同資料夾的 `AGENTS.md` 教學規則（一次只改一件事、用簡單繁體中文、改完教孩子測試、留一個小問題、保留孩子的作品）。
這份檔案補充這款遊戲的結構，讓你不用重讀整個專案就能上手。

## 這是什麼遊戲
俯視角的「機關闖關」（像 Roblox 的 obby、Temple Run）。探險家上下左右走，躲開會定時冒出來的尖刺、撿寶石，
等「雙燈籠大門」打開後衝過去，在時間限制內碰到寶箱就逃出神殿。被尖刺打到會回到最後點亮的火把（檢查點）。
藏的學校概念：**倍數**（陷阱每 N 秒冒出來）、**公倍數／最小公倍數**（兩個燈籠同時亮，門才開）、**時間計算**（限時、還剩幾秒）、控制變因（複習）。

## 怎麼玩
- WASD 或 ↑↓←→ 走路，R 重來。
- 主場景是 `scenes/level_1.tscn`，按 F5 開始。
- 上方顯示「時間（過了幾秒）／剩下幾秒／寶石數」。孩子要看「時間」來數陷阱的節奏。

## 檔案結構
```
scenes/
  level_1.tscn   主關卡「神殿」：下層走廊（練習陷阱、倍數走廊 A/B/C）→ 右邊通道 → 上層走廊（雙燈籠大門、最後陷阱、寶箱）
  my_room.tscn   「我的密室」：自由發揮用的空房間（已放好 1 個陷阱、1 顆寶石、1 扇大門、1 塊牆可複製）
  示範關.tscn     完成品範例：同一張地圖加上 2 隻會巡邏的聖甲蟲守衛（在 Godot 打開後按 F6 直接玩）
  player.tscn    探險家（玩家），群組「玩家」
  trap.tscn      尖刺陷阱（一條 3 格長），上面的字會自動顯示「每N秒」
  door.tscn      雙燈籠大門（兩個燈籠是它的子節點 燈籠A、燈籠B）
  lantern.tscn   燈籠（數字由大門設定，不要直接改燈籠）
  gem.tscn       寶石，群組「寶石」
  checkpoint.tscn 檢查點（火把），群組「檢查點」
  exit.tscn      寶箱出口，群組「出口」
  wall.tscn      一格牆，可複製
  enemy.tscn     巡邏守衛（第二堂才用，程式現在是空的）
  示範_守衛.tscn  示範關專用、已做好的守衛
scripts/
  clock.gd     全域時鐘（autoload 名稱 Clock）。Clock.秒 = 關卡開始後過了幾秒。陷阱和燈籠都看它，所以節奏會對齊
  sfx.gd       全域音效（autoload 名稱 SFX）。用法：SFX.播("coin")，可用 coin / win / hit / door / fire
  level.gd     關卡大腦：時間、剩餘時間、寶石、重生點、過關、時間到。@export：時間限制
  player.gd    探險家移動、受傷()、回到(位置)。@export：移動速度
  trap.gd      尖刺：t >= 週期 且 t 除以週期的餘數 < 冒出秒數 時冒出來。@export：週期、冒出秒數
  door.gd      兩個燈籠同時亮 → 開門「開門秒數」秒；有人站在門口不會關。@export：燈籠A每幾秒亮、燈籠B每幾秒亮、開門秒數
  lantern.gd / gem.gd / checkpoint.gd / exit.gd / enemy.gd / 示範_守衛.gd
課本/          給小朋友的上課講義（.docx 可編輯、.pdf 可列印）
assets/sprites/ 自己畫的神殿素材（CC0）＋ Kenney 外星人角色（CC0）。player.png 是探險家，角色選擇/ 裡有別的顏色
assets/sfx/     Kenney CC0 音效
```

## 可以在檢查器（Inspector）直接調的數值
- 探險家（player.gd）：`移動速度`
- 尖刺陷阱（trap.gd）：`週期`（每幾秒冒出來）、`冒出秒數`（冒出來停多久）
- 雙燈籠大門（door.gd）：`燈籠A每幾秒亮`、`燈籠B每幾秒亮`、`開門秒數`
- 關卡根節點（level.gd）：`時間限制`
→ 這些「改數字」的事，請讓孩子自己在檢查器做，不要用 AI 代勞。

## 重要設計（別改壞）
- 陷阱和燈籠的節奏一律用 `Clock.秒` 算，不要改成各自用 Timer，否則「第 12 秒一起冒出來」這種倍數現象就對不上。
- 陷阱在第 0 秒不會冒出來，第一次是在第「週期」秒。燈籠也一樣。這樣「出現的時間」剛好就是週期的倍數。
- 燈籠每次只亮 0.5 秒，所以只有在「兩個週期的公倍數」那一秒門才會開（例：4 和 6 → 第 12、24、36 秒）。
- 地圖每格 64px，整張地圖往下移 32px，讓上方時間列不會擋到陷阱的「每N秒」字。
- 場景檔（.tscn）裡用中文命名的屬性要加引號，例如 `"週期" = 3.0`，否則 Godot 讀不到。
（已用機器人模擬驗證：能拿滿 8 顆寶石過關、門在第 12 秒開、被尖刺打到會回到火把、時間到會失敗。）

## 哪些不要動
- 不要把節點改成用程式 `_draw()` 畫；保留真正的場景節點，孩子才點得到、拖得動。
- 不要刪掉 `玩家`、`寶石`、`檢查點`、`出口`、`守衛` 這些群組，程式靠它們運作。
- 輸入動作名稱、autoload 名稱（SFX、Clock）維持英文。
- 不要動 `AGENTS.md`（教學規則）。
