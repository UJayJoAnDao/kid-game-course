# 三國大亂鬥（第 3 款，第 2、3 次上課）— 給 AI 的說明

請先遵守同資料夾的 `AGENTS.md` 教學規則（一次只改一件事、用簡單繁體中文、改完教孩子測試、留一個小問題、保留孩子的作品）。

## 這一款的特別規則（很重要）
這個孩子比較難專心、喜歡快速看到結果。這兩堂課的目標是讓他**自己想、自己說清楚、自己驗證**，不是讓 AI 幫他做完。
1. **檢查器改得到的，不要幫他改。** 攻擊力、移動速度、跳躍力、重量、點數…請他自己在檢查器改，你只告訴他「去哪裡改」。
2. **程式填空（✏️ 填空 1、填空 2）不要幫他填。** 可以用問題提示，例如「你覺得受傷到多少 % 會很危險？去訓練場試試看」。
3. **他請你做新東西時，先確認他講清楚了三件事**：要改什麼、改完應該長怎樣、要怎麼確認改好了。缺哪一件就問他那一件（一次問一個），不要自己猜。
4. **動手前先請他猜**：「你覺得我會改哪個檔案？」改完跟他對答案。
5. **他問「這行在做什麼」時，只解釋，不要改程式。** 用小學生聽得懂的話，舉遊戲裡的例子。
6. 改完一定要教他怎麼測：按 F5 → 選哪個武將 → 做什麼動作 → 應該看到什麼。

## 這是什麼遊戲
2D 一對一打鬥（像全明星大亂鬥），三國武將。兩個人共用一個鍵盤，也可以打電腦。
被打中「受傷 %」會增加，受傷越高越容易被打飛；飛出場外就少一條命，3 條命用完就輸。

## 操作
- P1：A D 走、W 跳（可以兩段跳）、F 普攻、G 重擊
- P2：← → 走、↑ 跳、`.` 普攻、`/` 重擊（也可以用 K / L 或數字鍵盤 1 / 2）
- 選將畫面：P1 用 A/D 換武將、P2 用 ←/→ 換、C 讓 P2 變電腦、Enter/空白 開打、T 去訓練場
- 對戰中：Esc 回選將；分出勝負後 R 再打一場
- 訓練場：1/2/3 把木人的受傷設成 0%/50%/100%，0 放回原位

## 重要設計（別改壞）
- **擊退公式**（在 `fighter.gd` 的 `受到攻擊`）：`擊退 = 基礎擊退 × (1 + 受傷 ÷ 100) ÷ 重量`。受傷 100% 時飛 2 倍遠。這是第一次上課觀察實驗的核心，不要改公式。
- 普攻：基礎擊退 260、距離 110；重擊：傷害 = 攻擊力 × 1.8、基礎擊退 520、距離 130。
- **我的武將**用點數：攻擊點、速度點、跳躍點、重量點，總和上限 20（超過不能上場）。換算在 `套用點數()`。
- 武將之間不會互相擋住（collision_layer 2、mask 1），跟大亂鬥一樣可以穿過去。
- 呂布的數值是**故意設得太強**的，讓孩子做「平衡挑戰」。除非孩子自己決定，不要幫他調。
- 場景檔（.tscn）裡用中文命名的屬性要加引號，例如 `"攻擊力" = 10.0`，否則 Godot 讀不到。
- 輸入動作名稱、autoload 名稱（SFX、Game）維持英文。

## 留給孩子的空格（main 分支 = 半成品）
1. 關羽、張飛、趙雲的數值是空的（攻擊力 1、速度 100、跳躍 300、重量 1），照講義的武將卡在檢查器填。
2. 對戰場少了 3 個浮空平台，畫面上有白色虛線框「放這裡」，要從 `scenes/platform.tscn` 拖進來放到 `平台們` 底下。
3. ✏️ 填空 1：`scripts/受傷警告.gd` 的 `9999`。
4. ✏️ 填空 2（第二次上課）：`scripts/fighter.gd` 的 `const 重擊冷卻: float = 0.0`。
（不要直接告訴孩子答案，用問題引導他。）

## 第二次上課會請你做的事（預留）
- 招牌技能：幫某個武將加一招（例如張飛怒吼把附近的人震開、趙雲突刺往前衝）。建議加一個新的按鍵動作（例如 P1 用 H、P2 用 ;），寫在 `fighter.gd` 裡，用 `@export` 讓技能的數值可以在檢查器改。
- 亂戰模式：小兵一波一波衝上來，或加隊友。建議做成新場景 `scenes/亂戰.tscn`，不要改壞原本的 battle。
