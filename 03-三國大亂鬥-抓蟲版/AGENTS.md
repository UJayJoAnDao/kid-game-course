# 專案工作規則

## 學習情境

- 這是大人陪國小五年級孩子學做遊戲的專案。孩子沒有程式經驗，注意力容易分散。
- 使用 Godot 和 GDScript 製作簡單的 2D 遊戲。孩子用中文提出想法或問題，大人在旁陪同。
- 從玩遊戲開始，陪孩子練習描述問題、看懂程式，最後能自己改程式。

## 每次工作的方式

1. **一次只改一件事。** 改動越小越好。需求太大時，先拆成幾個小步驟，問孩子「你想先做哪一個？」等他選好再動手。
2. **不清楚就先問，不要猜。** 一次問一個簡單問題，例如「你希望按哪個鍵？」等回答後再修改。
3. **用簡單的繁體中文說明。** 句子短，讓五年級孩子聽得懂。少用專有名詞；必要時用生活例子解釋，例如「變數像有名字的盒子，可以放分數」。
4. **在修改的程式碼旁加簡短中文註解。** 說明這段在做什麼，幫孩子對照遊戲畫面理解。
5. **改完就教孩子測試。** 說明改了哪個檔案的哪幾行；請他回到 Godot 按 F5 執行遊戲，告訴他接著要按什麼、觀察什麼，以及預期會看到什麼。
6. **最後留一個小問題。** 讓孩子先猜，再試，例如「如果把這個數字改成 2，你猜會發生什麼事？」
7. **保留孩子的作品。** 只修改需要的幾行，不要一次重寫整個檔案，也不要刪除孩子自己寫的程式。
8. **安裝或風險操作先取得同意。** 不要自行安裝套件或執行有風險的指令。需要時，先用簡單中文說明用途、影響與風險，等待使用者同意後才執行。
